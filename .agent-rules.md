# ELIX OS Architectural Rules & Guardrails — Baseline 2.0

> **IMMUTABLE ARCHITECTURAL DIRECTIVES**
> The following rules govern all development, refactoring, and feature additions across the ELIX OS App Bridge subsystem.

---

## 1. WebSocket IPC Bus Port & Server Invariants (GUARDRAIL 1)
- **Port Binding**: The authoritative local IPC bus MUST bind to `ws://127.0.0.1:7391`.
- **Singleton Lifecycle**: `WebSocketServer` instantiation is a singleton managed via `ensureIpcServer(7391)` / `LocalIpcServer`.
- **Event Dispatchers**: The broadcast mechanism in `packages/apps/app-bridge/src/tui/test-harness.ts` and `src/native-window-host.ts` must dispatch real-time events (`TOOL_INVOKED`, `APP_STATE`, `WINDOW_CLOSE`) directly to all active clients in `wss.clients`.

---

## 2. Frontend Receiver & CSP Meta Tags (GUARDRAIL 2)
- **CSP Integrity**: All demo and packaged apps (`com.elix.notes`, `com.elix.calculator`, etc.) MUST retain the permissive local IPC CSP header:
  ```html
  <meta http-equiv="Content-Security-Policy" content="default-src * 'unsafe-inline' 'unsafe-eval' data: blob:; connect-src * ws://127.0.0.1:* ws://localhost:*;" />
  ```
- **Auto-Reconnecting Client**: Frontend `index.html` files must include the auto-reconnecting `WebSocket('ws://127.0.0.1:7391/?appId=' + appId)` client and message dispatchers for app capabilities (`create_note`, `search_notes`, `delete_note`, `calculate`, etc.).
- **Generator & Template Sync**: When `rebuildDemoApps` or packaging tools execute, template source files (`demo-apps/`, `src/demo-apps/`) and installed directories (`~/.elix/apps/`) must remain synchronized with identical WebSocket client handlers.

---

## 3. Native Window & Process Teardown (GUARDRAIL 3)
- **Electron Lifecycle**: Standalone Electron desktop windows must maintain:
  ```javascript
  webPreferences: {
    nodeIntegration: true,
    contextIsolation: false,
    webSecurity: false
  }
  ```
- **Detached DevTools**: Auto-launch detached DevTools (`win.webContents.openDevTools({ mode: 'detach' })`) on window launch.
- **Physical Teardown**: `closeApp()` and `closeWindow()` (Option 10) must physically invoke:
  * `win.destroy()`
  * Synchronous process tree termination via `taskkill /F /T /PID ${pid}` (Windows) and `process.kill(pid, 'SIGKILL')` (POSIX)
  * Immediate client socket cleanup to decrement active client counters accurately.

---

## 4. Message Envelope Forward Compatibility (GUARDRAIL 4)
- All future features and capabilities must layer on top of this verified IPC bus format without breaking existing message envelopes:
  ```json
  {
    "type": "TOOL_INVOKED",
    "tool": "app_com_elix_notes_create_note",
    "capability": "create_note",
    "appId": "com.elix.notes",
    "args": { ... },
    "payload": { ... },
    "result": { ... }
  }
  ```
